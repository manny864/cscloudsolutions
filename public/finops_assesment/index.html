Conectar al tenant del cliente

No hay servidor intermedio: los datos viajan de Azure a este navegador y de acá solo salen cuando descargás los archivos. El token vive en la memoria de esta pestaña (en inicio de sesión interactivo, en el almacenamiento de sesión) y se pierde al cerrarla.

Entra ID no permite canjear un client secret desde un navegador (bloqueo CORS AADSTS9002326), así que el secreto nunca se escribe acá. Generá el token con este bloque de PowerShell (sin módulos, sirve Windows PowerShell 5.1), que te pide el secreto de forma oculta y deja el token en el portapapeles. Dura entre 60 y 90 minutos; si vence a mitad de la extracción, la herramienta pausa y te pide uno nuevo.

      Qué tiene que habilitar el cliente (permisos mínimos)
      
    
        
  • Por qué Reader solo no alcanza: Reader lee recursos, pero las consultas de costos y el pronóstico son acciones de Cost Management que requieren Cost Management Reader (y en contratos EA, la opción “ver cargos” habilitada).
    • 
        
  • Reader y Cost Management Reader sobre el grupo de administración raíz (ideal) o sobre cada suscripción a relevar. Con eso alcanza para costos, Resource Graph, Advisor, Defender for Cloud, backup, políticas, RBAC y métricas.
    • 
        
  • Reservations Reader a nivel tenant (opcional) para reservas y savings plans. No aplica con Lighthouse: las reservas no se delegan.
    • 
        
  • Service principal del cliente: App registration en su tenant, client secret con vencimiento corto (por ejemplo 30 días) y los roles anteriores. No requiere permisos de Microsoft Graph.
    • 
        
  • Usuario del cliente o invitado: la persona necesita los roles anteriores. La primera vez se le pide consentimiento para la app de CSCloudSolutions (permiso delegado de Azure Service Management).
    • 
        
  • Azure Lighthouse: el cliente despliega la delegación con Reader + Cost Management Reader hacia el tenant de CSCloudSolutions y entrás con tu cuenta corporativa. Es obligatorio cargar el Tenant ID del cliente para no mezclar suscripciones de otros clientes.
    • 
        
  • Clientes CSP: Cost Management por API solo responde si el partner habilitó la visibilidad de costos. Si falla, el resto del relevamiento sigue igual.
